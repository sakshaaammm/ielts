# IELTS Academy - Modern Institute Homepage

A modern, professional, and fully responsive homepage for an IELTS Institute built with React, TypeScript, and TailwindCSS.

## 🚀 Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd ielts-academy
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm start
   # or
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 🎨 Design Choices

### Color Palette
- **Primary Blue**: Educational blue (#3B82F6) - represents trust, professionalism, and learning
- **Secondary Orange**: Warm accent (#F59E0B) - creates energy and motivation
- **Success Green**: Achievement color (#10B981) - highlights success and progress
- **Clean Neutrals**: Professional grays and whites for optimal readability

### Typography
- **Inter Font**: Modern, clean sans-serif font for excellent readability across devices
- **Clear Hierarchy**: Proper font sizing and spacing for content organization
- **Responsive Text**: Scales appropriately for mobile and desktop

### Layout Philosophy
- **Mobile-First**: Responsive design starts with mobile and scales up
- **Minimal & Clean**: Plenty of white space for easy scanning
- **Card-Based**: Organized content in digestible cards with hover effects
- **Split Layouts**: Hero section uses split layout for visual balance

### Interactive Elements
- **Smooth Animations**: CSS transitions and hover effects for modern feel
- **Accessibility**: Proper contrast ratios and semantic HTML
- **Performance**: Optimized images and efficient CSS for fast loading

- **Large Desktop (1440px+)**: Maximum container width, enhanced spacing
